**IT HUNT** is a modern software solutions and technology academy web portal designed to showcase IT services, professional internships, technology courses, events, career opportunities, admissions, testimonials, and company information.

The platform combines an educational academy experience with a software-development-studio identity, providing visitors with information about production-oriented internships, technology programs, professional courses, events, and career opportunities.

The project is designed to run locally with a lightweight Node.js server and can be deployed to **Vercel** using the included serverless configuration.

# 🏗️ Application Architecture

The project follows a lightweight architecture rather than a traditional React/Vite/Nuxt application.

```text
                    ┌─────────────────────────┐
                    │       IT HUNT Web       │
                    │        Portal           │
                    └────────────┬────────────┘
                                 │
                  ┌──────────────┴──────────────┐
                  │                             │
           ┌──────▼──────┐              ┌──────▼──────┐
           │ HTML / Vue  │              │ CSS Theme   │
           │ UI Layer    │              │ & Styling   │
           └──────┬──────┘              └─────────────┘
                  │
           ┌──────▼───────────┐
           │ CONTENT_DATA     │
           │ Central Content  │
           │ Configuration    │
           └──────┬───────────┘
                  │
           ┌──────▼───────────┐
           │ Environment      │
           │ Configuration    │
           └──────┬───────────┘
                  │
           ┌──────▼───────────┐
           │ Node.js HTTP     │
           │ Server           │
           └──────┬───────────┘
                  │
           ┌──────▼───────────┐
           │ Vercel / Local   │
           │ Deployment       │
           └──────────────────┘
```

The application uses Vue 3 from a CDN rather than a locally bundled Vue application. The main `index.html` loads Vue 3, `html2pdf.js`, centralized content data, environment configuration, and CSS assets.

# 🐛 Troubleshooting

## Port Already in Use

If port `5500` is occupied:

```bash
lsof -i :5500
```

Then stop the process:

```bash
kill -9 <PID>
```

Alternatively, change:

```env
PORT=5501
```

The development server also contains automatic port fallback behavior when the configured port is already occupied.

---

## Environment Changes Not Applied

Check:

```text
.env
env.js
js/envConfig.js
```

Restart the development server:

```bash
npm run dev
```

---

## API Requests Failing

Check:

```env
API_BASE_URL=
ADMISSION_API_ENDPOINT=
JOB_APPLICATION_API_ENDPOINT=
REVIEWS_API_ENDPOINT=
```

Make sure the backend API is running and accessible.

For production, do not use:

```text
http://localhost:3000
```

Instead configure the deployed backend URL.

---

## Images Not Loading

Verify:

```text
img/
```

and ensure the referenced filename matches the actual file name exactly.

For example:

```javascript
image: "img/logo_ithunt.png"
```

File paths are case-sensitive on many production environments.

* Vue 3 + Vite
* TypeScript
* Vue Router
* Pinia

This would provide:

* Component-based architecture
* Better type safety
* Better build optimization
* Code splitting
* Improved maintainability

# 🤝 Contributing

Contributions are welcome.

### 1. Fork the repository

```bash
git fork https://github.com/anoopithunt/ithun
```

### 2. Clone your fork

```bash
git clone <your-fork-url>
```

### 3. Create a branch

```bash
git checkout -b feature/your-feature
```

### 4. Make your changes

Follow the project's existing architecture and styling conventions.

### 5. Test locally

```bash
npm install
npm run dev
npm test
```

### 6. Commit

```bash
git add .
git commit -m "feat: add your feature"
```

### 7. Push

```bash
git push origin feature/your-feature
```

Open a Pull Request against the `main` branch.
